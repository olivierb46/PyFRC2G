Rotate the encryption key

  1. Generate a new key: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())" and download a backup above first.
  2. Set it in PYFRC2G_SECRET_KEY and put the previous key in PYFRC2G_SECRET_KEY_OLD, then restart.
  3. Click the button below: every stored value is re-encrypted with the new key.
  4. Remove PYFRC2G_SECRET_KEY_OLD and restart.
